我的求職與年收 200 萬策略
Q1：我的主要目標是什麼？

A：

我的目標不是單純「找到一份工作」，而是希望建立一個可以讓我達成年收 200 萬以上的收入模式。

目前可以分成兩條路：

第一優先：正職
期望年薪：160 萬以上
最理想：遠端或半遠端
希望以作品集、實務經驗、面試交流的方式取得 Offer
盡量避開需要上機考的公司
第二優先：接案＋正職／遠端工作
如果單靠正職無法達到年收 200 萬
就透過接案補足收入
目標是讓「正職收入＋接案收入」達到 年收 200 萬以上
Q2：為什麼我不想再把重點放在上機考？

A：

因為現在實際工作的開發方式，已經跟傳統上機考有很大的差異。

目前我在實際 Coding 時，會使用 AI Agent 協助開發，因此我真正工作的方式並不是完全依靠自己一個字一個字把程式碼打出來。

上機考卻通常要求：

限時
不使用 AI
一個字一個字輸入
在陌生環境下完成題目
有時還會考演算法或資料結構

這些能力跟我現在實際工作的方式並不完全相同。

因此，我不應該把大量時間花在「重新訓練自己成為一個很會上機考的人」。

我的策略應該是：尋找更重視實務能力，而不是上機考表現的公司。

Q3：那我要找什麼樣的公司？

A：

我要優先尋找：

重視作品集的公司
重視實務開發經驗的公司
重視產品經驗的公司
重視架構能力的公司
重視解決問題能力的公司
新創
中小型科技公司
外商
遠端團隊
半遠端團隊
有實際產品開發需求的團隊

看到職缺如果明確寫：

「需要上機考」
「演算法考試」
「LeetCode」
「多輪 Coding Test」

如果這是公司的核心篩選方式，而且自己沒有興趣準備，就可以降低優先順序。

不要把所有公司都當成自己的目標。

我要做的是找到「適合我的公司」，而不是強迫自己適應所有公司的面試制度。

Q4：如果不靠上機考，我要靠什麼證明自己的能力？

A：

最重要的就是：

作品集＋實務經驗＋面試表達能力

作品集不能只是：

「我做過一個 Vue 網站。」

而是要讓對方看到：

「這個人真的有能力把一個產品做出來。」

因此每個重要作品都應該能回答：

這個產品是做什麼的？
解決什麼問題？
我負責哪些部分？
使用什麼技術？
為什麼選這個技術？
遇到什麼困難？
我怎麼解決？
有沒有做效能優化？
有沒有考慮 SEO、Security、Testing、CI/CD？
最後產生什麼成果？
Q5：作品集應該做很多個嗎？

A：

不用。

與其做 10 個很普通的作品，我應該做 1～3 個非常完整的作品。

尤其是可以展現：

Vue / 前端能力
API 串接
狀態管理
元件設計
效能優化
Responsive Design
Authentication
權限管理
Testing
CI/CD
部署
Git workflow
AI Agent 輔助開發
實際產品思維

的專案。

作品集的目標不是證明「我會寫程式」，而是證明「我可以解決問題」。

Q6：我會使用 AI Agent，這件事情應該隱藏嗎？

A：

不需要。

反而可以把它變成自己的優勢。

重點不是說：

「我寫 Code 都靠 AI。」

而是說：

「我知道如何使用 AI Agent 提升開發效率，同時我能夠理解、審查、修改並維護 AI 產生的程式碼。」

這是完全不同的概念。

我真正要展現的是：

AI 使用能力＋工程能力＋判斷能力。

例如可以展示：

如何使用 AI Agent 快速建立功能
如何讓 AI 協助重構
如何讓 AI 協助寫測試
如何 Debug
如何 Review AI 產生的 Code
如何避免 AI 產生錯誤架構
如何設計 Prompt / Agent workflow
如何讓 AI 加速開發流程

這甚至可以成為作品集的一個特色。

Q7：如果正職真的找不到年薪 160 萬以上怎麼辦？

A：

不要把自己限制在：

「一定要找到一份年薪 160～200 萬的正職。」

可以改成：

「我要建立年收入 200 萬以上的職涯模式。」

例如：

正職 160 萬＋接案 40 萬＝200 萬

甚至：

正職 140 萬＋接案 60 萬＝200 萬

或：

正職 120 萬＋接案 80 萬＝200 萬

這樣思考會讓選擇變多。

Q8：接案應該怎麼定位？

A：

不要什麼案子都接。

我要逐漸建立自己的專業定位。

例如：

Vue / 前端工程師＋AI Agent 開發效率

可以接：

Vue 網站開發
前端系統開發
Landing Page
後台管理系統
API 串接
舊系統重構
前端效能優化
RWD
AI 功能整合
AI Agent workflow
MVP 開發

讓客戶知道：

「如果我要快速把產品做出來，可以找這個人。」

這會比單純說「我會寫前端」更有價值。

Q9：接案收入要達到多少才有意義？

A：

可以先設定階段性目標。

第一階段

每月接案：

10,000～20,000 元

先建立穩定案源。

第二階段

每月：

30,000～50,000 元

開始成為正職之外的穩定收入。

第三階段

每月：

50,000～80,000 元以上

這時候接案就已經不是零用錢，而是一個真正的第二收入來源。

例如：

正職 150 萬＋每月接案 4 萬

一年就是：

150 萬＋48 萬＝198 萬

再接一兩個比較大的案子，就有機會突破 200 萬。

Q10：我要怎麼找到不需要上機考的工作？

A：

不要只靠 104 海投。

我應該增加：

① LinkedIn

建立自己的專業形象。

讓別人看到：

我是 Vue / 前端工程師
我有實際作品
我會使用 AI Agent
我有產品開發能力
我可以遠端工作
② 獵頭

直接告訴獵頭：

「我希望找年薪 160 萬以上、偏實務導向、最好沒有傳統上機考的前端／軟體工程職缺。」

讓獵頭幫我篩選。

③ 人脈與內推

這可能比海投更重要。

因為如果有人直接把我的履歷交給 Hiring Manager，我就比較有機會跳過一些制式篩選。

Q11：我要不要繼續投 104？

A：

要。

但不要把 104 海投當成唯一策略。

可以把時間分配成：

30%：104

30%：LinkedIn／獵頭

20%：人脈／內推

20%：作品集＋接案

這樣比較像是在經營自己的職涯，而不是每天瘋狂按「應徵」。

Q12：我現在最重要的事情是什麼？

A：

不是一直找新的職缺。

而是先把自己的「求職武器」準備好。

我的優先順序應該是：

第一：整理履歷

讓履歷清楚呈現：

我能解決什麼問題。

第二：整理作品集

挑出 1～3 個最強的作品。

第三：準備面試故事

每個作品都能講：

背景 → 問題 → 我的做法 → 技術選擇 → 困難 → 解決方式 → 成果

第四：建立 AI Agent 開發案例

讓 AI 不只是我私下使用的工具，而是變成：

我的工程效率優勢。

第五：開始建立接案管道

不要等正職找不到才開始接案。

可以同步建立。

最後，我真正要追求的不是「一份高薪工作」

而是：

建立一個年收入 200 萬以上，而且不需要依賴傳統上機考的職涯模式。

我的理想狀態是：

🏢 正職

年薪 140～160 萬以上

＋

💻 接案

每年 40～60 萬以上

＋

🤖 AI Agent

讓我用更少的時間完成更多開發工作。

最後形成：

正職收入＋接案收入＋AI 提升生產力

＝

🎯 年收入 200 萬以上

而且我不需要把自己的職涯全部押在「我能不能在 60 分鐘內寫出一道 LeetCode 題目」。

我的目標不是成為最會考試的工程師，而是成為一個市場願意付高薪、願意找我合作，而且能用 AI 把事情做好的工程師。
