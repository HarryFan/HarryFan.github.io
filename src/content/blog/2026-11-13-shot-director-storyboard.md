最近做 The Midnight Signal Studio，我碰到一個很直接的問題：**故事有了，旁白有了，畫面也漂亮，但看起來還是太像有聲投影片。**

把靜態圖片換成影片，確實會好一點。可是山景、森林、雨景輪流播，如果只是旁白說到山就放山，說到下雨就放雨，觀眾仍然不知道自己站在哪裡、正在等什麼。

這次的故事剛好很適合拿來處理這件事：應龍出現在中國山區，主角聽見吼聲，卻始終看不到牠的全貌。我給製作流程的限制更嚴格：連龍的輪廓、爪子、巨大影子都不要出現。這是一部原創虛構故事，不是目擊紀錄。

**既然不能靠怪物出場，鏡頭就得讓觀眾願意一直聽。**

## shot-director 幫的是分鏡，不是按一下替你剪完

我用的是 [cinematic-skills 裡的 shot-director](https://github.com/AustinZ21/cinematic-skills/tree/c462c41/skills/shot-director)，這次固定參考 `c462c41` 版本。它是一份給 AI agent 閱讀的鏡頭設計指南，搭配運鏡、時間與空間、檢查清單等參考文件。

它不會自己吐出影片，也不是我先前提到的 FilmOps 分析程式。這次實際做的是：讓 agent 讀指南、寫分鏡、檢查素材，再交給剪輯流程執行。

我最喜歡它逼人回答的一件事：**這一鏡，讓觀眾多知道了什麼，或多感受到什麼？**

如果答案只是「這段空拍很美」，我就會再想一次它要不要留。

## 先把「有電影感」改成能執行的描述

以前很容易丟這種要求：

> 山區很神祕，鏡頭要有電影感，營造壓迫感。

這些詞可以表達喜好，卻沒有告訴剪輯的人要做什麼。我現在會改成下面這樣。這是我依這次故事整理的指令範例：

> 在第一聲吼叫前，切到窗上的雨。保持同一個視角，讓雨滴持續滑落，窗框仍留在畫面中。聲音出現時不要立刻換景，等尾音結束、留出反應的時間再切。窗外只有普通山林，不出現任何生物線索。

差別在於：有了可以選素材、排時間、驗收畫面的條件。

shot-director 將鏡頭描述拆成六個層次。我把它改寫成自己做素材剪輯時會問的問題：

| 層次 | 我實際會問什麼 |
|---|---|
| 主體與動作 | 是雨滴在流、霧在飄，還是人真的有動作？ |
| 景別 | 這裡要交代整片山，還是只看腳邊的濕地？ |
| 角度與高度 | 觀眾像站在現場，還是突然飛到山頂？ |
| 鏡頭與對焦 | 窗上的雨清楚，還是遠山清楚？原素材看得出什麼？ |
| 攝影機移動 | 原片真的在移動嗎？方向有沒有改變？ |
| 節奏與限制 | 留多久、在哪裡切、哪些東西不能出現？ |

這個分類來自指南的 [foundations](https://github.com/AustinZ21/cinematic-skills/blob/c462c41/skills/shot-director/references/foundations.md)，表格中的問題則是我針對現成素材的用法。

用素材庫有個現實限制：**分鏡可以要求一個鏡頭，但不能假裝手上的素材已經拍到了。** 看不出焦段，就不硬填 35mm；分不清是平移還是轉動，就記錄「向右重新構圖，移動方式未確認」。寫得精準，也包含承認不知道。

## 先排聲音，再決定哪裡不要切

  <figcaption>概念插圖：分鏡要能回答聲音出現時，觀眾應該留在哪個位置。</figcaption>
</figure>

這集的旁白和字幕已經做好，我不想為了新畫面把整段聲音重新生成。因此先把旁白提到地點、動作的時間，以及吼聲開始、結束的位置放在同一張表上，再安排鏡頭。

指南有音樂節拍的做法，但這一集的節奏來自旁白、雨聲與等待。我沒有硬套背景音樂的拍點。

以新版開場為例，前三鏡是這樣排的：

| 影片時間 | 畫面 | 這一鏡的工作 |
|---|---|---|
| 00:00–00:03.50 | 山峰與流動霧氣 | 先建立山區的距離與尺度。 |
| 00:03.50–00:07.25 | 山屋插入畫面 | 配合旁白第一次提到山屋，讓觀眾知道敘事者待在哪裡。 |
| 00:07.25–00:24.25 | 雨滴滑過窗玻璃 | 第一聲吼叫約在第 12.22 秒開始；保持同一個窗口，直到聲音結束後才離開。 |

第三鏡留了 17 秒。這不是忘了剪，而是這段的主角變成了聲音。

若吼聲一來就連切三個山景，觀眾會忙著辨認新畫面。我想要的是讓他待在窗後，開始懷疑聲音到底從哪裡來。

這是這次分鏡最實用的改變：**除了標記切點，也標記不能切的區間。**

## 固定鏡頭，不等於靜態圖片

<figure>
  <img src="/blog/2026-11-13-shot-director-storyboard/02-locked-camera.png" alt="窗仔與小機器人在固定的三腳架攝影機旁觀察雨窗，雨滴和樹葉在動，攝影機保持不動。" width="1536" height="1024" loading="lazy" />
  <figcaption>概念插圖：讓環境活動，不必每一鏡都推拉搖移。</figcaption>
</figure>

我原本要求這集至少九成使用動態影片。重剪時更清楚一件事：這個比例要算的是**真正的影片時長**，不能把圖片慢慢放大，就當作實拍動態素材。

固定攝影機拍到雨滴、風吹樹葉、霧穿過森林，畫面裡仍然有時間流動。尤其故事說人物停下來聽，畫面一起停止移動，環境卻繼續下雨，反而更合理。

新版的分鏡安排是 104 段剪輯片段、22 個動態來源，保留 82 秒的靜態插入畫面。以約 24 分 34 秒的片長計算，動態影片約占 **94.44%**。這是依時間線的來源類型統計，不代表每一個像素都在移動，也不是影片品質分數。

那 82 秒沒有硬湊成影片。山屋、設備、路線等特定資訊，短暫用靜態畫面交代，有時比塞一段不相干的素材更清楚。

## 先交代路在哪裡，觀眾才會在乎人走不走得出去

整理分鏡時，我也刪掉了幾段單看很好看的素材。

故事說的是石階，素材卻出現木階梯；敘事還在濕冷的山徑，畫面突然換成湖邊公路。這些素材本身沒有問題，但放在這裡，會讓空間關係變得模糊。

我的調整很簡單：山屋第一次被提到時先交代山屋；路線出現時給觀眾方向；真正到達出口，才出現出口畫面。不要為了畫面豐富，提前把故事還沒抵達的地方秀出來。

這個思路參考指南的 [time-and-space](https://github.com/AustinZ21/cinematic-skills/blob/c462c41/skills/shot-director/references/time-and-space.md)。對這集來說，空間連續性比再加一個漂亮轉場有用。

素材裡的山景也不會因此變成故事地點的實拍證據。故事設定在中國山區，來源不同的景物只是敘事示意，不能包裝成真實現場。

## 我的實際工具分工

這次流程可以寫成一行：

**故事與既有聲音 → 聲音時間表 → shot-director 分鏡 → 挑選素材 → MoneyPrinterTurbo 組接 → 字幕與混音輸出 → 檢查。**

其中 MoneyPrinterTurbo 實際執行了影片組接，字幕與最終音軌則由後續輸出流程處理。我沒有讓它用預設配音取代原本選好的聲音，也沒有把整個流程說成一鍵完成。

檢查不只看「檔案有沒有生出來」。這次保留 413 段原字幕，核對字幕文字，並抽查輸出音軌與原混音是否有時間偏移；聲音設計中一處銜接則依劇情時間做了修正。技術比對能抓掉軌、錯位等問題，但不等於完整的人類試聽。

素材整理也一起做了。下載後記錄來源頁、作者、授權資訊、內容分類，以及用在哪一集。缺少確切來源的舊檔先標成待確認，不能因為檔名寫著 Pexels 或 Pixabay，就直接當作已完成授權查核。

下次要找「雨窗、固定視角、至少 15 秒」，這些紀錄比一個叫 `final-final-02.mp4` 的檔名有用得多。

## 想試的話，可以先從三鏡開始

不必一開始就替半小時影片寫一百格分鏡。先挑一段 30 秒、有一個明確聲音事件的內容，寫三鏡就好。

想重現我這次參考的版本，可以把整份指南放進專案參考資料夾，保留它相對路徑下的文件：

```bash
git clone https://github.com/AustinZ21/cinematic-skills.git references/cinematic-skills
git -C references/cinematic-skills checkout c462c412c69b45a0e2bb827f55a1555c0738c0f9
```

接著請 agent 讀取 `references/cinematic-skills/skills/shot-director/SKILL.md`。這只是固定版本的專案參考做法，不代表已經安裝成所有專案都會自動啟用的全域 skill。

下面這段是我整理的起手指令，可以換成自己的故事：

```text
先閱讀 shot-director 的 SKILL.md 與這段影片需要的參考文件。
我要剪一段 30 秒的聲音懸疑故事，16:9，使用現成影片素材。
旁白與音效已確定，以它們的時間為準，不重新產生配音。

先寫三鏡分鏡。每鏡列出：
- 觀眾新知道或感受到什麼
- 開始與結束時間
- 主體動作、景別、視角、對焦與實際攝影機移動
- 素材需要具備的條件，以及缺少素材時的替代方案
- 聲音切點，以及聲音出現後必須保持畫面的區間

未知焦段、拍攝地點或器材請標成未知。
固定鏡頭可以保留環境動作；不要用圖片放大冒充動態素材。
最後檢查地點是否連貫，以及每次切換是否有理由。
```

## 這樣會比較有流量嗎？

我希望會，但現在不能拿剪輯規格當成成效證明。

這次做的是讓開場更快交代情境、讓聲音事件有足夠空間，以及減少沒有理由的畫面跳換。發布後才有機會從觀眾留存曲線觀察：人在哪裡離開？長時間聽聲音的段落留不留得住人？標題承諾的懸疑，開頭是否真的交付了？

「每三秒切一次」或「動態比例超過九成」，都不是我已經驗證的流量公式。對一部靠聲音講故事的影片，該切的地方切、該留下來聽的地方不急著走，才是這次真正想練的事情。
